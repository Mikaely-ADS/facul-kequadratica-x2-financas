Aplicação Web para Controle Financeiro
Este projeto foi desenvolvido com o objetivo de ajudar pessoas a organizarem melhor suas finanças pessoais de forma simples e prática. A aplicação permite registrar receitas e despesas, acompanhar gastos e visualizar informações financeiras de maneira mais clara, ajudando no controle do orçamento do dia a dia.

✨ Funcionalidades
A aplicação conta com funcionalidades como:


Cadastro de receitas e despesas;


Organização dos gastos por categorias;


Dashboard com gráficos para acompanhamento financeiro;


Filtros para pesquisa por período e categoria;


Alertas e sugestões para auxiliar no controle financeiro;


Interface simples e responsiva.



🛠️ Tecnologias Utilizadas
Durante o desenvolvimento do projeto, foram utilizadas as seguintes ferramentas:


Anti Gravity — Estruturação e desenvolvimento da aplicação;


Canva — Criação do design das telas e elementos visuais;


Replit — Ambiente utilizado para programação e testes;


Inteligência Artificial — Apoio na organização das ideias, criação de telas e definição das funcionalidades.

Seguindo diretrizes de design "Fintech Premium" e utilizando Next.js, TypeScript, Tailwind CSS, shandcn/ui, Recharts e Firebase.
